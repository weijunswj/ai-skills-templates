# N5 GitHub Governance and Truthful PR-Review Reconciler

Explicit-only skill for the current-main Toolkit N5 contract: deterministic
parent/direct-child governance, human-readable programme projections, bounded
large-parent mutation, truthful PR review inventory and finding disposition
evidence, and parent-managed Deferred Findings. It preserves A1-A4 and #295
authority boundaries and never owns review-thread mutation, Ready, merge, Web
finality, providers, workflows, or MCP.

The generic presentation model is portable and does not embed canonical state.
The Toolkit adapter supports distinct human-v1 markers, legacy v5 byte
compatibility, authority-defined history additions, observational provider
evidence, and deterministic pre-number/post-number PR bodies.

This skill is directly canonical. Use the local runtime and focused tests when validating it.
